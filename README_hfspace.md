# 🔍 MIR Project — Group 07

Live demo of the I-ILIA-014 Multimedia Image Retrieval engine.

- **Unimodal mode** — image-to-image search on a Cars dataset subset using CLIP ViT-B/32, ResNet50, HOG
- **Multimodal mode** — text-to-image and image-to-text search on Flickr8k via CLIP, OpenCLIP (LAION-2B), and BLIP ITM — live backbone selector with FAISS vector indexing

Built by **Sacha De Mulder** and **Roy Ebwelle** — UMONS, 2025–2026.

See the project README on GitHub for the full architecture and evaluation results.
